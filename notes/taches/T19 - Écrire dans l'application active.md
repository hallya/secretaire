# T19 · Écrire dans l'application active

Le texte dicté est tapé directement dans l'application au premier plan : la promesse « dans toute app ».

## Preuve
- **Avant :** Rien n'est écrit dans l'application active.
- **Après :** Le texte apparaît dans l'application active. ⚠️ Test physique sur le Mac de l'utilisateur, selon [[D-015 - Preuve des tests physiques]].
