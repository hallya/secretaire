# D-015 · Preuve des tests physiques

## Question
Comment prouver les tests physiques ?

## Contexte
Micro, haut-parleur et écriture dans une autre application ne peuvent être testés que sur le Mac de l'utilisateur.

## Options
Check-list manuelle exécutée par l'utilisateur, ou session Claude Code locale. À décider au moment des tâches concernées.
