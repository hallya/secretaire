# D-007 · Voxtral TTS pour la lecture

## Décision
Lecture vocale : Mistral Voxtral TTS.

## Ce qu'apporte Voxtral TTS
Sorti en mars 2026 : 9 langues dont le français, voix prêtes à l'emploi (anglais américain, britannique, français), clonage de voix à partir d'un court extrait, profils de voix réutilisables via l'API, réponse en flux. Prix annoncé : 0,016 $ les 1 000 caractères. La personnalisation des voix passe par la plateforme Mistral, donc par l'API (cohérent avec [[D-006 - Modèles via API distante]]).
