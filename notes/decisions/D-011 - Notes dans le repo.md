# D-011 · Notes dans le repo

## Décision
Notes du projet dans `notes/` du repo, `CLAUDE.md` comme point d'entrée.

## Pourquoi
Structure mise en place par l'utilisateur au commit initial. Raison constatée le 2026-11-01 : le repo est le seul endroit lisible par tous les espaces de travail. Une session Claude Code ne voit pas les documents du projet claude.ai.

## Ancienne structure
Fichiers : `decisions.md` (décisions prises et à prendre), `backlog.md` (tâches faites et à venir), `journal.md` (réussites, échecs, leçons). Remplacée par le format de [[D-017 - Format des notes]].
