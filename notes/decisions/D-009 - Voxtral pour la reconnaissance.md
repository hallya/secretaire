# D-009 · Voxtral pour la reconnaissance

## Décision
Reconnaissance vocale : Mistral Voxtral.

## Modèles
Voxtral Mini Transcribe V2 (par fichier, 0,003 $/min) et Voxtral Realtime (en direct, latence réglable sous 200 ms, 0,006 $/min). 13 langues dont le français. Une seule clé API pour la reconnaissance et la lecture.
